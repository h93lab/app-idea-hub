# Visual reference notes

The supplied metric-card reference is a dark charcoal/near-black surface with light grey text and one colored icon tile per card; it is not an acceptable final palette for this request because the purple, cyan, green, and orange tiles must be replaced by flat monochrome/electric-blue icons without colored containers.

The supplied hero reference uses a near-black base but also contains a blue-to-purple gradient across the right side and a blue glow near the bottom. These gradients must be removed. The target should use a flat near-black/pure-black hero surface, a thin dark border, white/grey typography, and electric-blue used only for selected labels, controls, progress, and icon strokes.

The user also provided a light settings reference and a multi-color catalog reference. Those surfaces should become the same dark card token as the rest of the app, with no white panels, pale cyan backgrounds, violet/amber/emerald/rose accents, or multi-hue chart/category markers.
